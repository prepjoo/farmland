# 스타랜드(별땅) 기획 요약

원본: Claude 문서 ‘별지점 새 기획서 v5 초안’(2026-10-13). 이후 바뀐 결정은 `changes.md`가 우선한다.

## 한 줄 정의
생일·기념일·전화번호 8자리로 찾은 ‘우리나라 속 나의 땅(별땅)’에 별을 찍고, 행운 카드와 함께 선물하는 서비스.

## 왜 오나
- “내 생일은 우리나라 어디일까?”라는 호기심.
- 남에게 보내고 싶은 선물 카드(입소문).
- 해마다 기념일에 새 카드가 열려 다시 찾아옴.

## 원리
- 국가지점번호 = 구역 글자 2개 + 숫자 8자리(앞 4 동쪽 ×10m, 뒤 4 북쪽 ×10m).
- 같은 8자리가 100km 구역마다 한 번씩 → 육지 후보 보통 10곳(6~13곳). 사용자가 하나를 고른다.
- 별땅 한 칸 = 10m × 10m = 100㎡(약 30평). 실제 소유권과 무관한 기념 표시.

## 1단계 기능
1. 번호 넣기: 생일 / 기념일(첫 만난 날·결혼기념일 등) / 전화번호 / 숫자 8자리. 연인은 두 사람 MBTI로 추천 별(선택).
2. 전국 후보 별 지도 + 목록에서 고르기, 고른 이유 한 줄.
3. 내 별땅: 지도(전국 ↔ 확대해서 10m 칸), 국가지점번호 우표, 땅의 수호 카드, 올해의 카드, 행운의 방향.
4. 선물: 동의 후 선물 링크, 기념 땅문서 이미지.
5. 기억하기: 첫 화면 D-day(이 기기에만), 휴대폰 달력(.ics), 보관함, 홈 화면에 추가.
6. 모든 화면 아래 고정: [내 위치 번호](지금 서 있는 칸의 국가지점번호) · [긴급 신고](119·112).
