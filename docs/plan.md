# 귀땅 FarmLand 기획 요약 (v4 — 오늘의 행운)

원본: Claude 문서 ‘귀땅 FarmLand 사이트 개발 기획안 v4 — 오늘의 행운’(2026-10-18). 이전 판(v1~v3)은 비교용으로 Claude 문서에 남아 있다.

## 한 줄
귀땅은 오늘의 행운번호와 행운 장소를 보여 주고, 그 이유를 투명하게 설명하는 무료 사이트다. ‘행운을 예측한다’가 아니라 ‘오늘의 행운을 발견한다’.

## 첫 화면 (번호 → 장소 → 이유)
1. [오늘의 행운번호 받기] → 만 19세 확인(처음 한 번) → **행운 추첨기**에서 공 6개(5게임 A~E).
2. **행운 룰렛** 22칸(오늘의 카드)이 멈춘 방향으로 지도 화살표 → 오늘의 행운 장소(1등 나온 판매점이 있는 시·군·구 + 판매점 하나). 전국 모드는 17칸 시·도 룰렛.
3. **긁는 카드**로 이유 보기(오늘의 카드 + 번호 이유 + 장소 이유). [바로 보기] 버튼.
4. **행운 카드 공유**(날짜·번호·장소·자료 기준 회차·오락용 문구).

## 메뉴 4개 (휴대폰은 아래 탭)
오늘의 행운(/) · 행운 장소(/place) · 나만의 행운(/me: 생일·기념일 번호, 둘의 번호·궁합땅) · 내 귀땅 마을(/my). 그 밖에 /learn(국가지점번호란?), /here(내 위치), /sos(긴급 신고).

## 미룬 것
데이트 행운길, 귀농귀촌 퀴즈, 계절 이벤트, 캐릭터 꾸미기 세부, 특산물, 지역 소개 페이지, 로그인·이웃·알림, 토요일 맞춰보기·지난 번호 통계(당첨번호 자료 출처 확인 뒤), 광고·제휴.

## 개발 순서
0 규칙·자료(약 1주) → 1 만들기(약 3주, 서버 없음) → 2 시험(약 2주, 2030 5~8명 + 1주 비공개, 법률 검토) → 출시 관문 → 전국 공개 → 3 넓히기 → 4 로그인·수익.
